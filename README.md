Everything in this repo follows it: use Omar's words, label anything uncertain

## Pass criteria this covers

- A framed case for each piece the sitemap calls for (live project + case #2),
  not a bare screenshot or a title.
- Each case has the three beats (problem / what I did and decided / what came
  of it) and could only describe this project.
- A specific person, with a before/after showing the difference from generic AI copy.
- Speaks to the one audience and points at the one action (try the live project) — no "results-driven" filler.

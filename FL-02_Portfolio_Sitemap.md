## 1. The Sitemap (sketch)

```
                         HOME
   Hero: "I ship AI-assisted things." 
   Primary CTA ─────────────►  TRY THE LIVE PROJECT
   Proof strip: 2 case cards          │
       │  (click through)             │
       ▼                              ▼
   PROJECTS                         [live project
   ├─ Live project (pinned, CTA)      opens / new tab]
   └─ Case study #2 (short)          /
       │                            /
       └──── back to home ◄────────┘

   ABOUT  (6 lines max, one block)
   └─ back to Projects

   (no separate Contact page — see change below)
```

Just four blocks. Every block either supports the claim or pushes toward the single action.

---

## 2. Does Every Page Earn Its Place?

| Page/block | Serves the claim? ("I ship AI-assisted things") | Serves the one action? (try the live project) | Verdict |
|------------|-----------------------------------------------|----------------------------------------------|---------|
| **Home (hero)** | States the claim in one line. | Carries the single primary CTA to the live project. | KEEP — this is the landing page. |
| **Projects / case studies** | Proof: the work itself shows AI-assisted things that shipped. | Live project is pinned first with its own CTA. | KEEP — this is the belief-builder. |
| **About (short)** | Quick credibility: the human behind the ship, my "verify everything" standard. | Links back to Projects → live project. | KEEP but tiny — reviewer context, not a detour. |
| **Contact (separate page)** | No — adds nothing to the claim. | No — the action is *try*, not *contact*. | **CUT → footer CTA** (email/DM) on every page. |
| Blog / Tools / resume section | No need — nothing here proves shipping. | Active distraction. | **REJECTED** — "pages just because." |

**Tempting pages I resisted:** Blog, Tools/Stack page, separate Resume. None of them move a FlyRank reviewer toward trying the live project.

---

## 3. What the Pressure Test Already Told Me (pass criterion)

**Change I'll make:** drop the standalone **Contact** page and put a one-line email/DM link in the footer of every page.
**Why:** my one action is *try the live project*, not *contact*. A Contact page is a detour; a footer never interrupts the path to the CTA.
**Second (smaller) adjustment:** About stays a compact block, never a long essay — maximum 6 lines.
